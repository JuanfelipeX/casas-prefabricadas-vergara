# casas-prefabricadas-vergara
Sitio web para Casas Prefabricadas Vergara, desarrollado con Astro. Proyecto enfocado en presentar modelos de casas prefabricadas, exhibir proyectos, fortalecer la presencia digital de la empresa y facilitar el contacto con clientes potenciales en Vergara, Cundinamarca y municipios cercanos.

# Casas Prefabricadas Vergara

Primera versión demostrativa de un sitio web para presentar la propuesta de Casas Prefabricadas Vergara, inspirar a clientes potenciales y facilitar el contacto desde Vergara, Cundinamarca y municipios cercanos.

## Tecnologías
- Astro 5
- HTML semántico y CSS responsive
- GitHub Actions y GitHub Pages

## Ejecutar localmente
Requiere Node.js 22 o compatible.

```bash
npm install
npm run dev
```

Para compilar y revisar la versión de producción:

```bash
npm run build
npm run preview
```

## Publicación
El workflow `.github/workflows/deploy.yml` compila el proyecto y lo publica en GitHub Pages cuando se actualiza `main`.

URL esperada: https://JuanfelipeX.github.io/casas-prefabricadas-vergara/

Si no se publica automáticamente, ve a **Settings → Pages** y selecciona **GitHub Actions** como fuente.

## Pendiente antes de mostrar a clientes
- Confirmar el teléfono y enlace de WhatsApp con los propietarios.
- Reemplazar imágenes de referencia por fotografías autorizadas de proyectos reales.
- Validar modelos, materiales, cobertura, precios, tiempos y garantías.
- Revisar textos, marca y datos de contacto.

Esta es una demo visual inicial, no una oferta comercial definitiva.
